# 🎫 SupportFlow

En plats för organisationens IT-support!

Skapa ett ärende, följ vad som händer och prata med supporten
via kommentarer. Supportpersonalen kan prioritera, ta ansvar
och hjälpa till att lösa problemen.

## 🌐 Testa appen

👉 [Öppna SupportFlow](https://supportflow-adamkosovic.up.railway.app)

Använd endast testuppgifter och ett unikt testlösenord.

## ✨ Vad kan man göra?

- 🔐 Skapa konto och logga in
- 📝 Skapa och följa supportärenden
- 🔎 Söka, filtrera och sortera
- 💬 Kommentera och se ärendets historik
- 🚦 Ändra status och prioritet som supportpersonal
- 🙋 Ta ansvar för ett ärende
- 📊 Se statistik i en översikt
- 📱 Använda appen på mobil och dator

Medarbetare ser sina egna ärenden.
Supportpersonal kan hantera alla ärenden.

## 🛠️ Byggt med

**Angular · TypeScript · ASP.NET Core · C# · PostgreSQL**

Även Entity Framework Core, ASP.NET Identity, Docker
och GitHub Actions används. Appen körs på Railway.
